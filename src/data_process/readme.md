# AP001 右手矩阵力点位与数据索引

本文档按照 `force_chart.py` 和 `RIGHT_FORCE_POINT` 的实际逻辑整理。
代码使用下面的关系读取和绘制力值：

```python
x, y = force_points[dot_index]
value = data[dot_index]
```

因此，矩阵中的数字不是力值，而是数据索引：

```text
0：没有传感器位置，或是 DUMMY_POINT
n：对应 data[n - 1]
```

矩阵行方向为图像上方到下方，列方向为左到右。矩阵是按照实际坐标压缩后的显示矩阵，
不包含完整的 `340 × 470` 空白画布。完整坐标仍以 `heat_map_dot.py` 中的
`RIGHT_FORCE_POINT` 为准。

## 数据顺序

六组数据顺序固定为：

```text
0: 拇指
1: 食指
2: 中指
3: 无名指
4: 小指
5: 手掌
```

如果矩阵中的值为 `n`，实际力值读取方式为：

```python
force_value = finger_force[finger_id][n - 1]
```

## 订阅程序使用的 CNN 索引矩阵

`thumb_force_matrix_subscriber.py` 保留原始索引矩阵，并按照实际点阵方向生成新的
CNN 索引矩阵。矩阵中的数字 `n` 表示该位置读取对应区域的 `data[n - 1]`。
